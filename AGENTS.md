# Regles agent

1. Lire `docs/STATE.md` en entier avant toute modification.
2. Ne pas regenerer un fichier existant : appliquer un patch cible.
3. Mettre a jour `docs/STATE.md` (fait / prochaine action / journal) apres chaque tache.
4. Respecter les conventions figees. Toute deviation se discute avant.
5. Ne pas toucher aux fichiers hors du perimetre demande.
6. Aucun offset en dur hors de `src/core/offsets/`.
